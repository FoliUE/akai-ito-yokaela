# Templates de referencia

Estos archivos quedan como referencia visual de la etapa anterior, cuando las notas nuevas se armaban a mano en HTML.

Ahora el flujo recomendado es:

1. Crear o completar la hoja con `tools/notes-manager/nueva_hoja.bat`, `./tools/notes-manager/nueva_hoja.sh` o `tools/notes-manager/nueva_hoja.command`.
2. Completar `note.json`, `mica.note` y `leo.note`.
3. Usar la sintaxis documentada en [FORMATOS.md](../FORMATOS.md).

- `template-clasico.html`: estructura base simple y limpia.
- `template-fecha-especial.html`: pensado para aniversarios, viajes o días importantes.
- `template-recuerdo-con-foto.html`: orientado a una foto con más protagonismo y un texto más contemplativo.

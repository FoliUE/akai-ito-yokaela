# Templates de referencia

Estos archivos son ejemplos para copiar y adaptar cuando quieras armar una nueva nota a mano.

- `template-clasico.html`: estructura base simple y limpia.
- `template-fecha-especial.html`: pensado para aniversarios, viajes o dias importantes.
- `template-recuerdo-con-foto.html`: orientado a una foto con mas protagonismo y un texto mas contemplativo.

Todas las plantillas de esta carpeta estan preparadas sin spoiler para la nota de Mica.
